# Small strided Copy prefetch

Purpose: reduce GPU frame-tail peaks without changing the six game tiers, CPU raster baseline, Alpha/Key semantics, network, or challenge scoring. Execution is inline under the user's standing instruction to proceed without intermediate approvals.

Evidence: test-only actual-loop trace on stable a476 BIT failed after 3600 qualifying frames at1995+250Alpha: work16.62267ms, wall33.27731ms, logic4.34953ms, build2.379ms, scene8.499ms, HUD1.04579ms, other0.34935ms; health0. Instrumented BIN is not a production score. HUD glyphs use packed14x18 sources and1920-byte destination stride; legacy Copy makes18 row reads. Existing full-background CopyStream is already burst/FIFO DMA and remains unchanged. Rejected onchip command staging was slower in sameBIN A/B/A and is rolled back.

Options: a separate CDMA duplicates existing hardware; software HUD reduction changes presentation and may hide transitions. Selected: extend the existing CachedKeyStream FIFO/aligner and two-outstanding writer to small strided Copy, preserving pixels and ABI. This reuses the full-row write-credit idea illustrated by verilog-axi axi_fifo (https://github.com/alexforencich/verilog-axi); no third-party code or dependency is imported, no novelty claim.

Contract: new trailing Boolean enableSmallCopyPrefetch defaults false throughout generator/top/render/dense; CLI --small-copy-prefetch requires Key prefetch and untrimmed Key write pipeline. Eligible Copy: width2..16 even, height1..32, word-aligned packed source, halfword-aligned destination, even destination stride strictly larger than width*2, nonoverlap. Key retains original eligibility/texture-cache path. Eligible Copy fetches the packed source once through existing DDR reader, reuses FIFO16, credits a full row before AW, pipelines at most2 row writes, and copies all valid lanes INCLUDING colorKey pixels. Contiguous Copy still uses CopyStream exclusively. All other Copy uses legacy path. No RAM or command/capability ABI expansion.

Completion must wait for all reads, accepted AW/W/B and errors to drain; preserve tag, ordering, WSTRB edges, 4KiB splitting, health/pixel accounting. An errored command may partially write, but must not corrupt the following Fill/Alpha/Key. Preserve six tiers786 exactly,1024, and3640 capacity.

Gates: new real RenderEngine tests RED/GREEN; aligned/halfword+stride1922/4KiB, magenta, fallback height33/source+2/odd width/contiguous, delayed AW/R/W/B, bad RRESP/RID/RLAST/B and next-command retirement. Relevant Key/Copy/Alpha/arbiter tests; full software integration for retained trace. Generate fresh one-module RTL; all final setup/hold domains positive before loading. Then same production BIN A/B/A plus normal challenge/5s hold. Keep default disabled absent repeatable benefit; restore known normal MENU on failure. Never Flash, CPU optimization, or a 60FPS claim based only on averages.

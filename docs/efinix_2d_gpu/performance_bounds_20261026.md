# 当前性能边界与缺口（2026-10-26）

这份账本区分已知接口上限、必要工作量下界和实际测量。尚未证明达到硬件极限；未知量保持未知，不拿理论带宽或重叠等待推算虚假净收益。

## 已固定的接口与必要流量

本工程ddr3_parameter.vh为DQ_WIDTH16、AXI_DATA_WIDTH128，board_top/DDR控制器及最终时序报告的SDRAM CK均400MHz，core为100MHz。因DDR双沿传输，物理数据引脚原始峰值为16×2×400MHz/8＝1.6GB/s；读写共享这组数据引脚，且真实可用值还受刷新、行切换和调度影响。128位AXI也不能说明窄事务必然充分使用每拍，Sapphire已有upsizer。

960×540、HUD72时，每次实际背景Copy为960×468 RGB565：读898560字节、写898560字节，共1797120字节。即使不计任何开销，按上述共享物理峰值至少1.1232ms。显示每帧至少读取一份完整RGB565图像1036800字节；二者在60Hz下已要求至少170.0352MB/s，不含精灵、HUD、列表或CPU访问。

上述170MB/s是必要流量下界，不能当作总实际流量，也不能因此称DDR利用率只有10.6%。GPU有效字节计数未包含全部显示/CPU访问、upsizer填充或控制器物理传输，需另取证。

## 固定1040阶段中已经能核算的部分

重算封存Alpha硬件A/B/A原始数据，三组共72个阶段窗口，fixture及字节匹配，100MHz换算。Alpha提前读版本Full平均5238.473us，GPU read957488字节、write有效999926.667字节、cache170944字节；这些是阶段测量，不是普通游戏总work。

这些固定阶段程序使用LOCAL纹理资产（initframe list network=0、bullet_init_local_assets），普通游戏各窗口则确认V3_READY network=1、mode=LIVE、count=1024。两者资产来源不同：固定阶段的缓存命中和零rcredit不能直接推广到普通游戏。

Key阶段read恰为1040×16＝16640字节的描述符，cache恰为(1039×64＋256)×2＝133504字节。Alpha130个12×12的前景cache恰为130×144×2＝37440字节。因此这些固定fixture的所有前景均已由纹理Cache提供，没有新增纹理容量的证据。

Full读字节还能拆为：898560背景＋1171×16描述符＋40192 Alpha背景读取＝957488。写有效字节为898560背景＋37440 Alpha＋63926.667 Key。对齐/透明掩码会使接口拍数与有效字节不同，不能用这些数直接当DDR PHY字节。

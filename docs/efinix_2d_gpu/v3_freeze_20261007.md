## 3 1024：主机容量通过，完整固件未通过

默认BULLET_OBJECT_CAPACITY仍512，只用独立编译参数尝试1024。主机UBSan完成600个真实交互tick：命令不超过1161，实际可见峰值≥1000、Alpha峰值≥125，1025请求拒绝；只证明容量/逻辑，不证明板端FPS。

完整1024互动固件链接失败：官方124KiB ram区 **overflowed by27904 bytes**，失败map保留，没有生成/下载1024 BIN。不是256MB DDR总容量不足，而是扩大命令暂存及仍保留的旧路径对象后，固件BSS加代码和4KiB栈超出原软件区。`v3_runtime`本来已经在私有DDR0x02d00000，但main的其他BSS并未因此自动搬走。未缩栈、关闭检查、修改官方BSP、删除CPU比较或重放来强行装下；2048没有尝试。后续1024需要明确的私有DDR暂存区迁移与容量审核，不能把这项失败说成实现成功。

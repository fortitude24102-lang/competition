## 定位与等价约束

实际RV32 GCC13的-Os反汇编确认，原GPU coordinate每次执行DIV，构建每个对象的x/y及Alpha位置均调用它。新源码加编译期断言，要求负数右移保留符号，再使用q8>>8；实际生产模块已无DIV，调用处使用srai8。先试过可移植unsigned互补写法，目标仍有分支/额外指令，仅作为试验保留，最终使用本平台的原生指令。

[GCC整数实现说明](https://gcc.gnu.org/onlinedocs/gcc/Integers-implementation.html)明确规定其负数有符号右移采用符号扩展。这里依赖已检查的编译器语义，未假装是所有C实现通用的规则。它与原向下取整逐值相同，包括INT32_MIN；其结果再减2也不溢出。

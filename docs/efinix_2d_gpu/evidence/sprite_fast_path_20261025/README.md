## 借鉴来源与实现选择

- [SDL，14f79fa2](https://github.com/libsdl-org/SDL/blob/14f79fa20e98800a6b9a276bd29697011c8a889b/src/video/SDL_surface.c)：SDL_BlitSurface负责裁剪/矩形检查，SDL_BlitSurfaceUnchecked调用底层blit，内部按需要选择层次。

这里借鉴“已满足完整覆盖条件时跳过通用处理”的机制，使用本项目已有append及裁剪函数，没有复制库实现或引入依赖。源快照及Git提交/SHA256保留于包内github-sources；SDL文件自带许可，LVGL许可也随快照保存。

实际RV32 -Os原sprite每对象使用96字节栈，保存大量寄存器。简单拆函数后，GCC又将仅调用一次的裁剪内联回来；使用noinline保持裁剪分离，新热函数栈16字节。目标代码检查先因96>32失败，最终16通过；还核对了真实链接ELF的调用及栈指令，未拿CPU基础绘图的同名sprite冒充GPU函数。它是此函数的静态栈报告，未测全系统栈高水位。

无符号边界比较同时排除负坐标；先转unsigned再减72避免新增有符号溢出。size仅私有调用点的8/12/16，容量满时visible为0，外层仍清空全部计数，不允许部分帧当成功。

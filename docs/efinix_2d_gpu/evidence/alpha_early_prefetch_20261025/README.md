## 机制与借鉴

借鉴[MiSTer blitter双行重叠](https://github.com/gmcnaught/mister-fpga-blitter/blob/c4407e41e8566fe094adac4da71448db7b1ef5f6/README.md)的思路，在当前行写入/像素处理期间读取下一行前景和背景，复用既有两组33字队列，没有导入上游RTL或依赖。限宽≤16、源/目标区域分离、逻辑目标行不重叠；两行即使半字错相，每组队列最多18字。宽行、单行和原位操作保持既有路径。

另核对[verilog-axi的axi_fifo_rd](https://github.com/alexforencich/verilog-axi/blob/master/rtl/axi_fifo_rd.v)：FIFO_DELAY按接收的burst预留返回数据容量。本板DdrQosArbiter目前只在队列全空时接收Render读取，后续可单独评估按容量接收；这项尚未实现，不能记作本轮收益。研究快照保留MIT说明，SHA256为`ecdb21c322732e8e185c6a1408438565d6990f852a8f271b5442e878174a20aa`。

## 采集失败和修复

r1严格解析拒绝候选Copy日志的半行`COPY_BOARD_STOP,result=0,h`，因此中止并恢复正常菜单，不计作候选成绩。根因是共享采集器看到停止前缀便退出。提交a040ab9仅等待完整换行；V3停止行另拒绝result=01。15个真实采集条件输入先红后绿，完整SoftwareOnly＋ShapeLut回归和独立审查通过。r2全部重跑，资格、工作量、评分和停止字段检查未放宽。失败原始日志保留。

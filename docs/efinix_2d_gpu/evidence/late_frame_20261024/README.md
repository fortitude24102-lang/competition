原解析实现保留，开关默认关闭。构建入口新增`test-efinix-software.ps1 -ShapeLut`，要求独立Interactive/FrameList输出与显式板端/PC地址，不覆盖release。正常固件开启查表，探针固件单独保留；没有新增运行期私有控制字或GPU ABI。

# V3 interactive resource sources and licenses

These new package files contain project-original procedural art generated by `tools/build_bullet_assets.py`: star/circuit arena, six bullet shapes, player fighter, glow and three enemy fighters. No third-party game source is included. Only these procedural background/atlas files are dedicated to the public domain under CC0-1.0.

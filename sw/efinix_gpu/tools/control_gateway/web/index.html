专项指标定义与测量范围

软核已测工作占比＝板端计时的逻辑更新＋命令构建时间，除以同一测量期墙钟时间；这是可归属到CPU的已测部分，不是完整CPU占用率。驱动渲染调用含提交和忙等，PRESENT也含同步忙等；裸机总CPU仍可能一直执行。FPS增加时此比例可能上升，不能据此声称CPU被优化。


像素为硬件处理计数，包含透明色像素，不等于最终非透明输出。DDR数据为GPU侧有效字节，读取含列表描述符；利用率按单向400MB/s计算，不代表DDR物理总利用率。GPU busy包含PRESENT等待，不用它冒充算术单元忙碌率。


固定本地素材和全活动负载，顺序执行逻辑、构建、整帧列表和PRESENT，未启用CopyAhead，不含HUD与网口管理；没有改变CPU基础渲染。600帧专项结果不能替代普通游戏实测或3600帧＋保持阶段的性能挑战。
